# 📅 2026 年 8 月 17 日 - DSH 记忆系统搭建·绘心验证暴露引导问题·MacBook 两月交接

## 🚀 核心进展与成果 (Top 5 Actions)

1. **把 DeepSeek Harness 的记忆系统搭起来了** 🦿
   * 先建了双层全局记忆：全局 AGENTS.md（宪法级）加符号链接，项目层 AGENTS.md 按家园目录规则挂载，实测每次改动都实时注入系统提醒——跨会话记忆靠文件而不是模型记忆。
   * 搭完发现全局指令有字节预算会静默截断，马上做了分层改造：全局只留宪法，把 15 个通用记忆按四标准迁进独立的 memory 目录（20 个主题文件），配 MEMORY.md 索引，按需读取，全局从 102 行瘦到 89 行。
   * **感悟/核心洞察**：记忆要靠文件不靠模型记忆，分层 + 索引 + 按需读取，这套跟人脑的"存记忆不如记索引"是一个道理。

2. **收尾两件自动化：dsh-web 一键启动 + 每日简报移交** 🔁
   * dsh-web 一键启动，包装成 zsh 函数，一条命令自动拉起服务并弹开浏览器，不用再手动敲 localhost。
   * 让 DeepSeek Harness 接管了原本是 Claude Code 负责的企业家每日简报，修了 3 个 bug——超时失效（服务器慢速吐数据时永不触发）、数据永久丢失（失败条目被提前标记 seen）、批次和 max_tokens 调参，修复后精华从 1/3 提到 15/22，跑完从 2 小时 13 分压到 7 分钟。
   * **感悟/核心洞察**：工作重心在逐渐交给 DeepSeek Harness 了，从 claude code 到 harness 是一次静悄悄的交接。

3. **绘心 Flow 上线验证，ami 的困惑让我第一次意识到引导的重要性** 🚀
   * 部署上线后给一些人验证，给了 ami，发在干干和玉玉的群里，但是没有反馈，大家反馈意愿度不高；ami 最开始上传了淘宝的渲染图，不是手绘的——我第一次意识到引导的重要性，用户可能完全不知道你的产品是干什么用的。
   * 马上开始修：做了双模型图片排除，非绘画相关的图片弹出提示要求重新提交；在用户名输入页之前先告诉用户这是需要纸笔的产品；文案偏成人方向，不哄孩子；首页内容精简，把多余的去掉。
   * **感悟/核心洞察**：产品需要引导用户找到下一步入口、找到有趣的功能；还要靠社区让用户看到别人的画、点赞评论。

4. **老婆想做记账软件，我顺着她挖出了"一人公司金融产品"** 💬
   * 老婆想在淘宝、支付宝、抖音四五个渠道记账，每天记账很累。我跟她分析打通这些平台不现实，数据本身不能对外公开，替代方案是集中某一天用语音快速记，再导入工具。
   * 而我下一场比赛（9 月）想做的是系统——经过 8 月比赛，我越发知道想要的是系统，不是很多个 Agent 的系统，而是适合某一个场景规则的系统，金融记账产品可能不单单只是简单记账。
   * **感悟/核心洞察**：针对一人公司的记账或金融产品，垂直、针对性强，最主要的出发点是满足老婆的需求，她的需求点肯定要被满足。

5. **《哈萨比斯传》230 页：OpenAI 崛起、盖亚智能体、李飞飞的联想** 📚
   * 读到 OpenAI 的崛起，神经网络的崛起、transformer 的崛起、chatgpt2 的诞生，让 AI 天平向 OpenAI 倾斜，哈萨比斯没意识到语言的重要性，因为 AlphaZero 连胜围棋选手让他忽视了神经网络。
   * DeepMind 在打造盖亚智能体，希望连接自然和人工智能领域更快抵达 AGI，这让我联想到之前看到的公司理念，也在想李飞飞教授是不是参与过盖亚，因为她去谷歌工作过，ImageNet 的成功是否是被邀请的原因。
   * **感悟/核心洞察**：历史在重演，今天 OpenRouter、Agent 生态这些概念，其实十年前 DeepMind 就在想"连接物理和 AI 世界"这件事了。

## 🧠 知识摄取与挑战 (Learning & Challenges)

  * **记忆靠文件不靠模型记忆**：跨会话记忆，全局宪法 + 项目挂载 + 独立记忆目录 + 索引。
  * **字节预算静默截断**：全局指令超预算会被静默截掉，要分层瘦身。
  * **引导是产品第一课**：用户不知道产品干嘛的，需要引导下一步入口 + 展示有趣功能。
  * **双模型图片排除**：非手绘图片要拦截提示，产品定位要守住边界。
  * **系统 vs 单点**：一个场景规则的系统，比堆很多 Agent 更有价值。
  * **DeepSeek 涨价峰谷**：官方出峰谷定价（9-12、14-18 高峰），早起晚睡有了新的意义。
  * **面临挑战：**
    1. GOAI 复赛能否从 1280 名进 30 名，焦虑反复。
    2. 绘心验证反馈意愿度不高，需要更多真实用户。
    3. 从 claude code 到 harness 的过渡期，两个工具共存。
  * **下一步计划：**
    * 继续修复绘心验证暴露的引导问题。
    * 推进 DSH 记忆分层，让工具链更厚。
    * 记账金融产品方向继续构思，为 9 月比赛蓄力。
