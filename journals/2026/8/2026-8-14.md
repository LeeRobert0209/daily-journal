# 📅 2026 年 8 月 14 日 - DeepSeek Harness 部署实测·GOAI 数据溯源审校·企业危机之道

## 🚀 核心进展与成果 (Top 5 Actions)

1. **DeepSeek Harness 第一时间部署，9 项能力测试全绿** 🦿
   * 今天在电脑上第一时间把 Harness 从 GitHub 克隆了下来，大概 80MB，装上就上手测，用游戏软件去测它：飞行射击、3D 迷宫、塔防、3D 跑酷、Roguelike，还有粒子星云品牌页和 NEBULA 品牌站，9 项全绿。
   * 飞行射击是 720 行一个 HTML 文件，3 种敌机、双管齐射、计分、生命、音效、触屏全有，最高分还能存，最狠的是它自己跑 Node 模拟 DOM 和 Canvas 的回归测试，击毁计分、坦克三发击毁、扣命、重启复位，全绿；3D 迷宫是 DFS 随机生成，还自测了 30 次连通性保证没死路。
   * 还让它实现 10 秒 3D 动画，自己编了个小机器人发现一朵小花的剧情，4 幕配旁白，中途撞上 Chrome 沙箱问题它自己绕道换成 Playwright headless-shell 接着跑，真的有点东西。
   * **感悟/核心洞察**：harness 的核心价值不是让模型变聪明，是给模型装上执行闭环——写文件、跑测试、看结果、再修，这个循环是裸模型没有的，等于把生成代码升级成开发加 QA。

2. **顺手做了 A/B 对比：DSH 省 6 到 13 倍 token** 🚀
   * 同一个任务同一个模型，Claude Code 和 DSH 各跑一遍，快速排序 5.9 倍、番茄钟 12.8 倍、井字棋 9.5 倍——DSH 直接省了 6 到 13 倍的 token。
   * 累计 190 次调用、66.3 万计费 token，折算下来就几块钱。原因就俩：系统提示精简，步数少、上下文不反复读，省的可都是钱。
   * **感悟/核心洞察**：我之前理解 harness 是提升安全性的约束工具，实测才发现它是模型外面的执行框架，天天在用、早就是多 Agent 实践者了。

3. **GOAI 材料一页页核对，数据溯源把把关** 🔁
   * 今天凌晨完成所有 PPT、HTML 修改，结果拿着材料一页页核对，发现问题真的多：98.4% 那个数字是拿 NEA 的 1.6% 反推的，写成"超过 98%"才站得住脚，顺手把 3.94 亿那张数据卡删了。
   * 论文出处好几处不对，OsloMet 那句"成年人比儿童更容易恐惧犯错"一直没出处，8 月 12 号验证报告里就标了要改成 Stana 教授的表述，结果到今天才发现一直没执行，等于报告做完就扔那儿了；Global Market Insights 其实是我调研记录里的 Market Intelo 和 Dataintelo，全换过来了。
   * 成本那块更要命，demo 里写 0.005 元/次，拉代码一审计发现除了主链路还有 3 个旁路在偷偷调 API，完整链路 5 次调用实测才 0.002 元，想了想还是保留 0.005，报高保底。
   * **感悟/核心洞察**：VLM 读数字还会读错，98.4% 它能读成 8.4% 和 3.4%，最后全是肉眼一个个核的；验证报告是行动清单不是存档，标了就要划掉，不然等于白做。

4. **《哈萨比斯传》推进到 200 页，读到了企业危机之道** 📚
   * 读到 DeepMind 遇到的 NHS 医疗事件，推动受阻、招聘阻挠、合同条款被质疑、媒体污蔑，感觉比我现在的状态还要糟糕，我就有点释然了——伟大的企业都是要经历的，就看怎么面对危机。
   * 看到个很有意思的点：任务等级分 P0、P0 plus、P0 plus plus，我第一次是在 Claude Code 开发里见到的，没想到书里 DeepMind 早就这么分级了。
   * **感悟/核心洞察**：当项目受质疑、方向被怀疑、产出被无视，都会有 DeepMind 当时的沮丧，但管理者没陷在焦躁里，而是开始沟通寻求解法，即使 OpenAI 来抢市场挖人（挖走辛顿的弟子苏兹克维），也要冷静应对。

5. **今天发了两篇小红书，一场认知觉醒** 💬
   * 第一篇是 GOAI 参赛视频，本来纠结研究数据有问题想删掉，半夜想通了：可能都没有人在意我这个 3 分钟视频，这只是我的个人记录，60% 就发吧，不要苛责自己，于是发出去了，现在 140 个小眼睛。
   * 第二篇是手机实拍 DeepSeek Harness 开头的鲸鱼吉祥物像素动画，13 秒，现在 4600 小眼睛、58 赞、20 收藏、12 评论，对于新账号是非常好的数据了。
   * **感悟/核心洞察**：放过自己、不追求完美主义再发，是认知的一大提升；内容的钩子有时候就是一个小细节（鲸鱼动画），比正经干货更抓人。

## 🧠 知识摄取与挑战 (Learning & Challenges)

  * **harness = 执行闭环**：写文件、跑测试、看结果、再修，裸模型没有这个循环，等于生成代码升级成开发加 QA。
  * **DSH 省 token 的原因**：系统提示精简 + 步数少不反复读上下文，同一个模型省 6-13 倍。
  * **数据溯源前置**：引用数字必须回到源头核，VLM 读数字会读错，报告标了就要当天划掉。
  * **验证报告是行动清单不是存档**：8/12 标了 OsloMet 要改，拖到 8/14 才发现没执行。
  * **企业危机应对**：DeepMind 的 NHS 事件证明伟大的企业都要经历质疑，关键是冷静沟通找解法。
