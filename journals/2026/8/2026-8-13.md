# 📅 2026 年 8 月 13 日 - david-voice 数字分身·harness 真相破圈·GOAI 数据溯源复盘·老婆出差归来

## 🚀 核心进展与成果 (Top 5 Actions)

1. **david-voice 数字分身——把"自己"自动化了** 🦿
   * 今天把最想自动化的东西给自动化了，就是我自己：让艾莉西亚从三年写的 98 万字五件事里把说话习惯抠出来——开口词、长流水句、三步走，连自己都没注意到的"然后然后"和数字狂魔都被抓出来了。
   * 专门做了份"去 AI 话"清单，让写出来的东西别带模板味，最后做成 david-voice 的 skill，只要说"用我的口气写"，它就能替自己起草五件事草稿。
   * 昨晚拿 8月12日 的五件事实测，读出来确实是自己写的味道，不是 AI 那种工工整整的东西——像给自己配了个能听懂话的复读机。
   * **感悟/核心洞察**：它自动化的不是流程，是表达习惯；三年每天几百字，攒着攒着攒出一个能替自己说话的备份，量变到质变是真的。

2. **harness 真相——Claude Code 本身就是 harness，早就在用多 Agent** 🔁
   * 起因是好奇 DeepSeek v4 pro 正式版跟自己用的版本差在哪，尤其是"harness"这个被媒体炒热的概念，一直以为是提升安全性的约束工具。
   * 让艾莉西亚设计对照任务实测：从零写个 tbl 工具，Flash 111.9 秒一次就过，Pro 224.9 秒跑了两次——一查才明白 harness 是模型外面的执行框架（接工具、管上下文、出错重试），Claude Code 本身就是 harness。
   * 发现自己天天在用、早就是多 Agent 实践者了；把这次实测落成了工具链体检 SOP，模板放知识库、触发条件写进记忆，以后哪个模型大版本更新、价格变动都跑一遍体检再决定换不换。
   * **感悟/核心洞察**：模型和 harness 是解耦的，就算 Claude 对大陆不可用，换模型就行，harness 还在——不敢全信新闻标题了，都要自己实测。

3. **GOAI 数据溯源复盘——底层信息放到最后才核，差点翻车** 🚀
   * 复盘 GOAI 提交整一轮：方向定下来后八九成精力全砸在开发、UI、逻辑这些看得见进展的东西上，拍视频、剪字幕、做 PPT、写简介，论文数据（98.4%、OsloMet 那句引用）却到提交前最后一刻才暴露问题。
   * 中间牵扯 deepseek、kimi 几个模型来回交流，Kimi 自己都承认编过 42% 那个焦虑数据，模型互相引用，错误一层层被放大。
   * 底层逻辑问题：这已经不是技术问题，是产品经理的专业素质——要对数字负责、对来源负责、对逻辑负责；以前是设计师看视觉表现，现在前期就是产品经理，这块专业度得慢慢补。
   * **感悟/核心洞察**：下次项目一开始就在调研阶段把数字溯源立起来，每个引用数字说清出处、模型给的数据回到源头核一遍，比最后十轮检查都省事。

4. **老婆出差归来 + 口播视频首发，跨过露脸表达最难一步** 💬
   * 老婆出差回来，到的时候已经是晚上 23 点；我先给柚宝洗澡、哄睡，再去楼下接她、帮拿行李箱——看到她心情就好很多，她是我生命中交流最多的人。
   * 老婆推掉了客户要吃的夜宵想早点回家，我说她能找到平衡客户、诱惑、疲劳三者的方式是很有勇气的。
   * 老婆说自己拍的口播 2 个视频今天都发在小红书上了，心情忐忑又激动——感觉跨过了露脸表达的最难一步，老婆表示我很棒。
   * **感悟/核心洞察**：跨过露脸表达的门槛，比想象中更需要勇气，而家人的一句肯定就是最好的正反馈。

5. **《这就是中国》+ deepseek harness 开源——民族自豪感** 📚
   * 看了《这就是中国》人工智能相关的一期，正好赶在 8 月 13 日梁文锋发布 deepseek harness 开源项目之后，内心对我们国家的人工智能发展涌起一股民族自豪感。
   * 历史上被打趴下过、落后发达国家 100 年，现在在逐步缩小差距；从人均生产总值到购买力平价，名词的更新就是一步步壮大的证明。
   * 从 2025 年的 deepseek v3/r1 看到中国 AI 崛起，manus 去新加坡被 meta 收购、国家不认可并拉回来——不能把国家数据送出国门。
   * **感悟/核心洞察**：deepseek harness 让我更愿意用国内产品了，现在用 deepseek 的 api，gemini 和 chatgpt 都不怎么用了——国家硬实力回来的时候，自然更得人心。

## 🧠 知识摄取与挑战 (Learning & Challenges)

  * **量变到质变**：三年每天几百字的五件事积累成 98 万字语料，最终蒸馏出能替自己起草的 david-voice——持续记录本身就是可复用资产。
  * **harness 不等于安全工具**：它是模型外层的执行框架（接工具/管上下文/重试），Claude Code 本身就是 harness，媒体概念要自己实测验证。
  * **模型与 harness 解耦**：模型可替换、harness 是基础设施——工具链切换的底层心态是"基础设施自有，模型只是算力"。
  * **数据溯源前置**：引用数字必须回到源头核一遍，Kimi 都会编数据，模型互相引用会放大错误——专业度从对数字负责开始。
  * **口播露脸是勇气门槛**：跨过之后表达会越来越自然，家人的正反馈是持续动力。
  * **面临挑战：**
    1. GOAI 初赛 8/16 截止，数据溯源问题需在最终提交前彻底解决。
    2. 产品经理素养补课：数字、来源、逻辑的核对能力要从头养，设计师思维要切换。
    3. 睡眠纪律：守 22 点合上 Mac，配合自动提醒机制。
  * **下一步计划：**
    * 工具链体检 SOP 模板落库，david-voice 继续在五件事起草中打磨。
    * 下一个项目一开始就在调研阶段建立数字溯源。
    * GOAI 最终定稿提交，复盘成果沉淀。
