## 🧠 知识摄取与挑战 (Learning & Challenges)

  * **单一模块 vs 系统的标尺**：拍照→反馈只有"分析"一个环节 = 半个 Agent，缺记忆、缺决策、缺自主循环；真正系统级的产品是多 Agent 协同。
  * **单 API + Orchestrator 编排**：决策执行分离，Orchestrator 模式（路由→执行→合成）比 Agentic Loop 省 70% 成本——多 Agent 成本可控的关键。
  * **比赛评分在任务闭环完整度**，不在 Agent 数量——最小可演示闭环优先。
