2. **给 DSH 接入了 Kimi 模型，一条 API Key 的排查** 🦿
   * 想用 Kimi 作为第二个模型提供商，结果一直报"API key is invalid"。我拿存的 Key 直接请求 api.moonshot.cn，返回 200——Key 本身有效，问题在路由配错：配成了 kimi-coding 订阅路由（OAuth 认证），我的是 Moonshot 平台普通 API Key，应该走 moonshotai-cn 路由。
   * 改对后 kimi-k2.5/k2.6/k3 全都能调通，默认模型设成 kimi-k2.6。
   * **感悟/核心洞察**：名字带 Kimi 的不一定接受 API Key，要看认证方式；排查要分两步——先证 Key 本身有效，再查路由对不对。
